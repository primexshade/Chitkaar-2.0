# Chitkaar 2.0 Design System

## Design Direction

The website should combine:

- Modern social-impact design
- Youth movement energy
- Editorial sophistication
- Documentary storytelling
- Warm human design
- Rich visual immersion

## Brand Characteristics

- Youthful
- Self-dependent
- Fearless
- Empowering
- Hopeful
- Trustworthy
- Human

## Color Direction

The color palette must be derived from the official Chitkaar logo.

Core visual directions include:

- Yellow / Gold
- Teal / Green
- Magenta / Purple
- Black
- Neutral supporting tones

The exact design tokens will be finalized during the design-system phase.

## Photography

Real Chitkaar photography should be prioritized.

Photography should communicate:

- People
- Community
- Action
- Emotion
- Authenticity
- Impact

Stock photography should be avoided when suitable real photography exists.

## Motion

Target visual richness: approximately 8/10.

Motion should support:

- Storytelling
- Navigation
- Hierarchy
- Feedback
- Discovery

All important interactions must remain usable with reduced-motion preferences.

## Accessibility

The design system must account for:

- Color contrast
- Keyboard navigation
- Focus states
- Touch targets
- Reduced motion
- Typography readability
- Screen-reader compatibility

## Component Philosophy

Components should be:

- Reusable
- Composable
- Accessible
- Responsive
- Consistent

Avoid creating one-off components when a reusable primitive is appropriate.
