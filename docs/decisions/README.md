# Architecture Decision Records

This directory contains important technical and product decisions made
during Chitkaar 2.0 development.

## Why ADRs?

Decisions should be documented so that future contributors understand:

- What was decided.
- Why it was decided.
- What alternatives were considered.
- What consequences the decision has.

## Format

Each decision should contain:

# ADR-XXXX: Decision Title

## Status

Accepted / Proposed / Deprecated / Superseded

## Context

What problem are we solving?

## Decision

What are we choosing?

## Alternatives

What alternatives were considered?

## Consequences

What does this decision mean for the project?

## Example

`ADR-0001-project-foundation.md`
`ADR-0002-content-management.md`
`ADR-0003-animation-system.md`
